# 🤖 بوت التداول الذكي V5 Ultra (النسخة النهائية الصافية — مجلد واحد رئيسي)

نظام تداول آلي وخبير إشارات لحظي لسلة 77 عملة رقمية على منصة Binance، مدمج بهندسة برمجية فائقة السرعة وإدارة صفقات دقيقة بنظام بصمة رقمية فريدة.
جميع الملفات متواجدة معاً في المجلد الرئيسي (`main/.`) مباشرة بدون أي مجلدات فرعية.

---

## 📂 محتويات هذه الحزمة (الملفات الضرورية فقط للتشغيل):

| الملف | الوظيفة |

| `golden_split_engine.py` | محرك الاستراتيجية المعتمد V5 Ultra بـ 3 معاملات: EMA 9/21/50 + RSI 45-75 + كسر قمة 15 شمعة. |

## 🚀 طريقة التشغيل:

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. ضبط توكن البوت والمشرف (اختياري / أو عبر المحادثة مباشرة):
```bash
export BOT_TOKEN="توكن_بوت_التيليجرام"
export ADMIN_CHAT_ID="8599225300"
```

### 3. تشغيل البوت:
```bash
python3 TITAN_UNIFIED_BOT.py
```

## 🎛️ أزرار البوت ووظائفها:

1. **🚀 التداول (`m:api`):** فتح لوحة ربط منصة Binance ومتابعة الأرصدة الحقيقية والتداول التراكمي.
2. **📡 الإشارات الحية (`m:sig`):** عرض أحدث إشارات الشراء والبيع الجديدة اللحظية بتنسيقها الكامل.
3. **🛡️ مراكزي المفتوحة (`m:guard`):** عرض صفقات Binance المفتوحة وصفقات استراتيجية البوت النشطة مع أسعار الدخول، والأسعار اللحظية، ونسبة الربح، وأهداف T1 و T2 ووقف الخسارة SL.
4. **⚡ مباشر (`bt:live:page:0`):** عرض حالة جمع وتحديث البيانات اللحظية لفريم 5 دقائق وفريم 1 دقيقة لـ 77 عملة وحالة المحرك (77/77 جاهز فوراً).
5. **📊 المحفظة (`m:port`):** عرض الحافظة الورقية التجريبية (رأس المال 400$، الكاش المتاح، إجمالي القيمة، الأرباح المحققة، والصفقات المفتوحة).
6. **📈 النتائج (`bt:page:0`):** عرض النتائج المعتمدة لباكتست 5 سنوات (14,440 صفقة، نسبة نجاح 98.48%، معامل ربح 28.65).
7. **📅 تقرير أسبوعي (`m:rep`):** ملخص أداء الأسبوع ونسبة الصفقات الرابحة.
8. **⚙️ الإعدادات (`m:set`):** التحكم في تشغيل وإيقاف تنبيهات الإشارات والحماية.
9. **ℹ️ حول البوت (`m:abt`):** شرح كامل ومختصر باللغة العربية لكيفية عمل البوت والاستراتيجية وطريقة الصفقات.
10. **👥 إدارة المستخدمين (`m:users`):** قائمة المشتركين المصرح لهم (خاص بالمشرف).
11. **📨 طلب وصول (`acc:req`):** يظهر للزوار الجدد لطلب الانضمام، ويرسل إشعاراً للمشرف مع زر موافقة فوري.
12. **✅ موافقة المشترك (`acc:allow:`):** يضغط المشرف عليه ليتم تفعيل المشترك الجديد فوراً ويصل المشترك إشعار ترحيبي للدخول للوحة التحكم.
